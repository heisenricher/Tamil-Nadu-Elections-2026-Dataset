# 🗳️ Tamil Nadu State Elections 2026 Dataset

A comprehensive, clean, and granular dataset detailing the results of the 2026 Tamil Nadu Legislative Assembly Elections.

## 📊 Dataset Overview
This repository contains 3 interconnected CSV files detailing the election results across all 234 constituencies. 

* **`Tamil_Nadu_State_Elections_2026_Details.csv`**: Granular candidate-level results (EVM votes, postal votes, win/loss flags).
* **`Tamil_Nadu_State_Elections_2026_Constituency_Metadata.csv`**: Demographic and voting stats for all 234 constituencies (turnout, district, reserved status).
* **`Tamil_Nadu_State_Elections_2026_Alliance.csv`**: Mapping of political parties to their broader alliances.

## 💡 Potential Use Cases
* Visualizing vote share across different districts.
* Analyzing the impact of postal votes vs EVM votes.
* Predicting future trends based on alliance performance.
